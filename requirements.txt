# Deployment dependency file for MEVA's Streamlit Community Cloud sandbox
# (streamlit_app.py). See docs/playground.md, "Browser Sandbox".
#
# Installs MEVA itself plus the optional "playground" extra (Streamlit).
#
# MUST be editable (-e). meva.mcp.registry.DATA_DIR is computed relative to
# registry.py's own __file__ (4 parents up -> repo root -> data/synthetic/synthea).
# A non-editable install copies package files into site-packages, so that
# arithmetic lands inside the venv instead of the cloned repo, and every
# public synthetic patient silently disappears (see
# docs/publishing-checklist.md, "Known packaging note", and the Streamlit
# Cloud incident this fixed).
#
# NOTE: if you change any importable name inside src/meva/ (e.g. add a new
# function to meva.playground.service) without also touching this file,
# Streamlit Community Cloud may skip re-running dependency installation on
# redeploy and keep serving a stale snapshot of the `meva` package, causing
# an ImportError even though the code is correct in the repository. Bumping
# the version marker below forces a fresh install on every dependency-
# relevant change.
#
# deps-version: 4
-e .[playground]
